# Roadmap

## Current Baseline

The repository now ships a runnable generic harness core:

- provider abstraction
- agent loop
- common tool registry
- memory, skills, tasks, and permissions
- CLI and REPL
- unit test coverage for the generic runtime

## Next Ecology Milestones

### 1. Data Access Layer

- CSV / TSV readers with schema inference
- GeoJSON and shapefile inspection
- raster metadata inspection
- file-to-table summarization

### 2. Ecology Analysis Tools

- biodiversity indicator calculation
- time-series trend summaries
- habitat and site comparison helpers
- observation quality checks

### 3. Ecology Reasoning Skills

- ecological report drafting
- survey result interpretation
- impact assessment reasoning templates
- literature extraction and synthesis workflows

### 4. Evaluation Harness

- curated ecology benchmark prompts
- expected-output scorers
- regression suites for domain tool quality
